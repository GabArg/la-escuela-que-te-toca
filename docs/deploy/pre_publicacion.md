# Checklist de prepublicación

- [ ] Rama master limpia y actualizada.
- [x] data/public presente y rastreable.
- [x] manifest.json válido.
- [x] SHA-256 válidos.
- [x] Suite completa aprobada.
- [x] Entrypoint app/app.py.
- [x] requirements.txt en la raíz y sin rutas locales.
- [x] Python 3.12 validado.
- [x] Rutas portables y nombres con capitalización correcta.
- [x] Reconstrucción desactivada por defecto.
- [x] No se requieren secrets.
- [x] GeoJSON con 529 IDs compatibles.
- [ ] URL pública.
- [ ] Prueba en incógnito.
- [ ] Prueba móvil en dispositivo físico.
- [ ] Grabación final del video.

Antes de publicar, integrar estos cambios en master mediante el flujo Git acordado y volver a ejecutar la suite desde un clon limpio.
