# Identidad visual

La identidad toma al mapa y a la lectura editorial como recursos centrales. No representa una escuela ideal ni califica territorios: abre preguntas sobre desigualdades con una voz precisa, sobria y cercana.

El verde bosque expresa continuidad y territorio; la terracota marca selección y contraste; el ocre queda reservado para cautelas y cobertura parcial. Los fondos cálidos reducen la apariencia de portal administrativo sin sacrificar contraste.

Principios:

1. primero la pregunta, después el indicador;
2. una visualización debe explicar una relación;
3. dato faltante y dato parcial siempre son visibles;
4. la comparación nunca declara un ganador;
5. la identidad no altera el significado analítico.
