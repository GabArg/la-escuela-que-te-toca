# Mapa territorial interactivo

El mapa contiene las 529 unidades GeoRef y permite seleccionar una unidad territorial equivalente. La selección se sincroniza con Provincia → Departamento mediante el estado de sesión.

El estado inicial es neutro. La lista opcional contiene asistencia 15–17, sobreedad, oferta relativa, hogares con internet y Lengua satisfactorio + avanzado. Todas provienen del perfil procesado.

- Dato disponible: escala secuencial verde bosque.
- Cobertura parcial: ocre con etiqueta explícita.
- Sin dato: neutral claro, nunca cero.
- Selección: contorno terracota.

En Lengua, una observación parcial no ingresa a la escala cuantitativa. El tooltip muestra territorio, provincia y valor o estado. La leyenda acompaña el color y el selector lateral sigue siendo una alternativa accesible. La geometría no se simplifica ni modifica.
