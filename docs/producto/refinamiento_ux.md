# Refinamiento de experiencia

La portada explica propósito y acción, ofrece selección persistente y sitúa el territorio en el mapa. El perfil abre con una frase estructurada a partir de dimensiones ya señaladas, seguida por un máximo de tres señales.

Historia muestra una variable por vez, mediana histórica y cautela 2020–2022. Comparables explica primero por qué dos territorios son comparables y solo después contrasta resultados. “Dónde mirar” reemplaza la tabla fría por filas editoriales y mantiene un orden alfabético no normativo.

Microcopy:

- partial se muestra como “Cobertura parcial”;
- distance se reserva al detalle “Distancia estructural”;
- “Sin dato” nunca se expresa como cero;
- las referencias son medianas o cuartiles, nunca puestos.

Las grillas pasan a dos o una columna según ancho. Quedan pendientes una auditoría formal con tecnologías asistivas, pruebas con usuarios y optimización para dispositivos de muy baja potencia.
