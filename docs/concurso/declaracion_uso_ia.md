# Declaración de uso de inteligencia artificial

Se utilizaron herramientas de OpenAI bajo supervisión humana:

- **ChatGPT:** apoyo en ideación, formulación de preguntas de investigación, discusión de alternativas metodológicas y estructura conceptual/narrativa.
- **Codex:** asistencia en escritura, organización y revisión de código, scripting, pruebas y documentación técnica.

También se utilizó asistencia de IA durante tareas exploratorias y de procesamiento mediante código. Sus resultados no se aceptaron automáticamente: las fuentes, definiciones, decisiones metodológicas, correspondencias territoriales, transformaciones y hallazgos fueron revisados y validados por personas responsables del proyecto.

No se empleó generación automática para manipular mapas, gráficos, datos o imágenes finales. Las visualizaciones de la aplicación se construyen programáticamente a partir de datos abiertos oficiales. La IA no sustituyó la interpretación metodológica ni la revisión humana.

Texto breve para formulario:

> Usamos ChatGPT para ideación y discusión metodológica, y Codex para asistencia de código, pruebas y documentación. Todo el trabajo fue supervisado y validado humanamente contra fuentes oficiales. No usamos IA generativa para alterar datos, mapas, gráficos ni imágenes finales.
