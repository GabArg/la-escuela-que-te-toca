# Declaración de uso de inteligencia artificial

Se utilizaron herramientas de OpenAI bajo supervisión humana:

- **ChatGPT / OpenAI:** apoyo en ideación, formulación de preguntas de investigación, discusión conceptual, revisión, apoyo metodológico, investigación y auditoría.
- **Codex / OpenAI:** asistencia de código, pruebas, refactorización, implementación supervisada y documentación técnica.

También se utilizó asistencia de IA durante tareas exploratorias y de procesamiento mediante código. Sus resultados no se aceptaron automáticamente: las fuentes, definiciones, decisiones metodológicas, correspondencias territoriales, transformaciones y hallazgos quedaron sujetos a decisión, revisión y aprobación humanas.

Según el proceso documentado para esta entrega, las visualizaciones finales no se generaron automáticamente sin supervisión y no se utilizó IA generativa para manipular imágenes finales. Las visualizaciones de la aplicación se construyen programáticamente a partir de datos abiertos oficiales. La IA no sustituyó las decisiones metodológicas, la revisión de fuentes ni la aprobación humana.

Texto breve para formulario:

> Usamos ChatGPT/OpenAI para ideación, discusión conceptual, revisión, apoyo metodológico, investigación y auditoría; y Codex/OpenAI para asistencia de código, pruebas, refactorización e implementación supervisada. Las decisiones metodológicas y la aprobación final fueron humanas. Según el proceso documentado, no hubo generación automática sin supervisión de visualizaciones finales ni uso de IA generativa para manipular imágenes finales.
